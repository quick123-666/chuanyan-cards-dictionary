# 川言 · 四川方言卡片

一个单文件 HTML 应用，把《四川方言词典》做成翻页卡片，可离线使用。

## 功能

- **卡片翻页**：左右箭头或键盘切换词条
- **词条列表**：多列网格浏览，点击跳转卡片
- **联动**：卡片切列表自动滚动到当前位置并高亮
- **A-Z 拼音首字母筛选**
- **语义搜索**：匹配词面 / 拼音 / 释义 / 关键词
- **录音**：点麦克风或按 `R` 键录音，关网页不丢
- **迷你播放器**：已录音词条显示播放 / 进度 / 删除
- **牛皮纸配色**

## 两种运行模式

顶栏有一个状态徽章，标明当前处于哪种模式。

### ● 已连接 · 录音存 audio/（推荐）

双击 **`start.cmd`**，浏览器会自动打开 `http://127.0.0.1:8765/`。

录音会**实时写成项目里的文件**：

```
audio/1.webm      ← 词条 1（阿爸）
audio/2.webm      ← 词条 2（阿兄）
```

好处：

- 录音进入版本库，`git push` 就能带走
- 换浏览器、换电脑、别人 clone 下来都有
- 清缓存不会丢
- 文件名是词条 id，可以在 `index.html` 的 `WORDS` 里对上

### ○ 离线 · 录音存浏览器

直接双击 `index.html`（`file://`）。录音只存在**当前浏览器**的 IndexedDB 里。

- 不需要起服务器，最省事
- 但**换个浏览器就看不到**，清站点数据就没了，`git` 也管不到

> `file://` 页面受浏览器沙箱限制，既不能写文件、也探测不到同目录的文件是否存在，
> 所以"自动存到项目文件夹"这件事必须靠本地服务器，这是浏览器安全模型决定的，不是实现取舍。

## 使用

**日常用服务器模式**：`start.cmd` → 自动开浏览器 → 录完音直接进 `audio/`。

服务器只监听 `127.0.0.1`（仅本机），不对外网开放。关掉窗口即停止。

手动启动：

```bash
py server.py            # Windows
python3 server.py       # macOS / Linux
py server.py 9000       # 指定端口（默认 8765，被占用会自动往后找）
py server.py --no-browser
```

## 录音文件约定

| 项 | 值 |
|---|---|
| 目录 | `audio/` |
| 文件名 | `<词条id>.webm`，如 `1.webm` |
| 格式 | MediaRecorder 直出的 `audio/webm` |
| 容量 | 每词条一份；同一词条重录会覆盖（这是既定设计） |

接口（供其他工具调用）：

```
GET    /api/recordings          -> {"ids":[1,2,3]}
PUT    /api/recordings/<id>     请求体 = 音频字节
DELETE /api/recordings/<id>
```

## 词条数据

- 来源：《四川方言词典》（扫描版 PDF）
- OCR：百度智能云高精度版（3x 分辨率，双栏切分）
- 切词：正则按"汉字 + 拼音 + 词性括号"规则切分
- 当前收录：**1263 条**

## 技术栈

- 原生 HTML / CSS / JavaScript，无构建工具
- 前端单文件自包含，CSS 内联、JS 内联
- 服务器仅用 Python 标准库，**不需要 pip install**
- IndexedDB 存储录音（离线模式）/ 文件存储录音（服务器模式）
- pypinyin（构建时生成拼音首字母，运行时不依赖）

## 已知限制

- OCR 切词有少量串条和错别字（扫描版质量限制）
- 例句翻译、例句字段为空
- 语义关键词为自动生成，非人工标注
- 浏览位置不记忆（关闭后回到第 1 张）
- 服务器只认 `127.0.0.1`，局域网共享需要自己改监听地址（有暴露风险）
