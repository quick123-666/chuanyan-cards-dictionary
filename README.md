# 川言 · 四川方言卡片

一个单文件 HTML 应用，把《四川方言词典》做成翻页卡片，可离线使用。

## 功能

- **卡片翻页**：左右箭头或键盘切换词条
- **词条列表**：多列网格浏览，点击跳转卡片
- **联动**：卡片切列表自动滚动到当前位置并高亮
- **A-Z 拼音首字母筛选**
- **语义搜索**：匹配词面 / 拼音 / 释义 / 关键词
- **录音**：点麦克风或按 `R` 键录音，IndexedDB 持久化，关网页不丢
- **迷你播放器**：已录音词条显示播放 / 进度 / 删除
- **牛皮纸配色**

## 使用

直接用浏览器打开 `index.html` 即可，无需服务器、无需安装依赖。

> 录音功能在 `file://` 协议下，部分浏览器（Chrome / Edge）可能需要授权麦克风。

## 词条数据

- 来源：《四川方言词典》（扫描版 PDF）
- OCR：百度智能云高精度版（3x 分辨率，双栏切分）
- 切词：正则按"汉字 + 拼音 + 词性括号"规则切分
- 当前收录：**1263 条**

## 技术栈

- 原生 HTML / CSS / JavaScript，无构建工具
- 单文件自包含，CSS 内联、JS 内联
- IndexedDB 存储录音
- pypinyin（构建时生成拼音首字母，运行时不依赖）

## 已知限制

- OCR 切词有少量串条和错别字（扫描版质量限制）
- 例句翻译、例句字段为空
- 语义关键词为自动生成，非人工标注
- 浏览位置不记忆（关闭后回到第 1 张）
